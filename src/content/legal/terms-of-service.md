## 4. Servers, invites, and membership

### 4.1 Servers

A server is created by a user who becomes its **owner**. Owners (and, where implemented, admins) manage invites, roles, channels, kicks, and bans. We do not pre-review every server; server owners must run their spaces in line with these Terms and the User Policy.

### 4.2 Joining

You join a server using an **invite code or link** (for example `https://echo.ieeecsvit.com/invite/...`) or by being added by a permitted member. Invites can expire or be limited to a maximum number of uses.

### 4.3 Leaving

Non-owners may leave a server at any time. Owners must **transfer ownership** or **delete the server** before leaving. After leaving, you may need a new invite to return, and you may not rejoin if you are banned.

### 4.4 Moderation

Permitted operators may **kick** or **ban** (and unban) members. A ban prevents the banned user from rejoining that server while the ban is in effect.

### 4.5 User controls

- **Report.** You can report another user from their profile (category and optional reason). Reports are submitted to Echo for review.
- **Hide messages.** You can hide another user's channel messages from your own view within a server. Hiding is viewer-only: the hidden user is not notified, and their messages remain visible to other members. It is not a global block.
